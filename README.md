# Apollo — виртуальный тур

Статический сайт (HTML + JS, без сервера и сборки) на базе [Pannellum 2.5.6](https://pannellum.org/).

```
3Dtour/
├─ panoramas/              ← ОРИГИНАЛЫ (HEIC), скриптом не изменяются
├─ tools/convert.py        ← конвертация HEIC → JPG
├─ tools/images.json       ← размеры и рассчитанные haov/vaov
├─ start-server.bat        ← запуск сайта на компьютере
└─ site/                   ← ЭТУ ПАПКУ заливать на хостинг
   ├─ index.html
   ├─ tour-config.json     ← все сцены и метки
   ├─ locales/ru.json      ← тексты интерфейса
   ├─ css/  js/  assets/  vendor/pannellum/
   └─ images/pano/  images/thumbs/
```

## Как посмотреть на компьютере

Дважды щёлкните `start-server.bat`: откроется http://localhost:8000.
Если открыть `index.html` двойным щелчком, тур не загрузится: браузер не даёт
читать файлы с диска. Нужен любой веб-сервер (в .bat используется встроенный в Python).

## Режим редактора: расстановка меток

Откройте **http://localhost:8000/?edit=1**. Слева появится панель:

1. **Клик по панораме** покажет `pitch` / `yaw` точки и поставит голубой крестик. Кнопка «Копировать»
   копирует координаты в буфер обмена.
2. **Новая метка:** выберите тип («Переход» или «Информация»), подпись и, для перехода, целевую сцену,
   затем нажмите «Добавить метку». Метка встанет в точку последнего клика.
3. **Метки на этой сцене:** здесь можно переименовать метку, удалить её или нажать «Переставить» и кликнуть
   по панораме в новом месте. Клик по метке на панораме выделяет её в списке; в режиме редактора
   переходов по меткам нет. Переходить между сценами можно через «Локации» или кнопку «Перейти».
4. **Сделать начальным видом:** сцена будет открываться под текущим углом и с текущим зумом.
5. **Геометрия:** `haov`, `vaov`, `vOffset` (см. ниже).
6. **Скачать tour-config.json:** замените им `site/tour-config.json`.

Правки автоматически сохраняются черновиком в браузере. Если обновить страницу, редактор предложит
восстановить черновик. Но на сайт правки попадут, только когда вы замените файл.

## tour-config.json

```jsonc
{
  "languages": ["ru"],              // добавьте "kk", "en", и появится переключатель языка
  "defaultLanguage": "ru",
  "venue": {                         // контакты; пустое или удалённое поле просто не показывается
    "address": { "ru": "..." },
    "phone": "+7 (708) 070-37-37",
    "whatsapp": "+7 (708) 070-37-37",
    "whatsappText": { "ru": "Здравствуйте! ..." },   // текст, который подставится в WhatsApp
    "instagram": "https://www.instagram.com/apollo_aktau/",
    "mapUrl": "https://2gis.kz/aktau/firm/...",       // ссылка «Поделиться» из 2ГИС
    "hours": { "ru": "..." }                           // необязательно: часы работы
  },
  "settings": { "firstScene": "01-mall-entrance", "autoRotate": -1.5, ... },
  "groups": [ { "id": "floor1", "title": { "ru": "1 этаж" } } ],
  "scenes": [
    {
      "id": "03-entrance",           // используется в ссылках: site/#03-entrance
      "group": "entrance",
      "title": { "ru": "Рецепшн" },
      "image": "03-entrance",        // → images/pano/03-entrance-4k.jpg / -8k.jpg
      "haov": 198.8, "vaov": 66.2, "vOffset": 0,
      "yaw": 0, "pitch": 0, "hfov": 100,   // начальный вид
      "hotSpots": [
        { "type": "scene", "target": "04-nachalo", "pitch": -8, "yaw": -15 },
        { "type": "info",  "pitch": -6, "yaw": -55,
          "text": { "ru": "Рецепшн" }, "description": { "ru": "Касса и администратор" } }
      ]
    }
  ]
}
```

* Любой текст можно писать строкой (`"Рецепшн"`) или объектом с языками (`{"ru": "...", "kk": "...", "en": "..."}`).
  Если перевода нет, показывается русский вариант.
* У перехода без `text` подписью становится название целевой сцены.
* Необязательные поля перехода: `targetYaw`, `targetPitch`, `targetHfov` задают направление взгляда после перехода,
  `rotate` поворачивает стрелку в градусах.
* Порядок сцен в массиве задаёт порядок кнопок «← →» и нумерацию.

### Частичные панорамы (haov / vaov)

Панорамы iPhone не полные 360°. `haov` — горизонтальный охват в градусах, `vaov` — вертикальный.
Скрипт рассчитал их из пропорций снимка, исходя из того, что вертикальный угол камеры iPhone ≈ 60°:
`vaov = 66.2`, `haov = ширина / высота × 66.2`.
Если на какой-то сцене предметы выглядят **растянутыми по горизонтали**, увеличьте `haov`; если **сжатыми**, уменьшите.
Удобнее подбирать в редакторе: блок «Геометрия» → «Применить». Если горизонт заметно выше или ниже центра,
поправьте `vOffset`.

## Добавить казахский / английский

1. Скопируйте `site/locales/ru.json` в `kk.json` (или `en.json`) и переведите значения.
2. В `tour-config.json` укажите `"languages": ["ru", "kk", "en"]`.
3. В конфиге добавьте переводы в тексты: `"title": { "ru": "Батуты", "kk": "Батуттар", "en": "Trampolines" }`.

В шапке появится кнопка языка. Выбор запоминается; можно также открыть ссылку с `?lang=kk`.

## Новые панорамы

Положите файлы в `panoramas/` и выполните:

```
pip install pillow pillow-heif
python tools/convert.py
```

Скрипт создаёт для каждого снимка `-8k.jpg` (компьютеры), `-4k.jpg` (телефоны) и миниатюру, а в `tools/images.json`
записывает подходящие `haov`/`vaov`. Затем добавьте сцену в `tour-config.json`.
Сайт сам выбирает качество по устройству. Принудительно: `?q=4k` или `?q=8k`.

## Публикация

1. Залейте **содержимое папки `site/`** на любой статический хостинг: Netlify, Vercel, GitHub Pages, Cloudflare Pages
   или обычный хостинг через FTP.
2. В `site/index.html` замените `https://example.com` на адрес сайта (3 места: `canonical`, `og:url`, `og:image`).
   Без этого превью в WhatsApp/Telegram не покажет картинку.
3. Картинка превью: `site/assets/og-image.jpg` (1200×630). Её можно заменить своей.

Шрифты Unbounded и Nunito подгружаются с Google Fonts. Если они недоступны, используется системный шрифт.
